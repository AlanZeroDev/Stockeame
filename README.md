#  Stockeame

### ¿Hay stock o no hay stock? Esa es la cuestión.

**Stockeame** es una aplicación web Full Stack de gestión y control de inventarios, pensada para simplificar el seguimiento de productos, registrar conteos físicos y detectar diferencias entre el stock registrado y el real.

El proyecto nace de una idea sencilla: gestionar un inventario no debería ser un dolor de cabeza.

>  **Estado del proyecto:** En desarrollo.

---

## ¿Que resuelve?

En muchos depósitos y empresas, los errores de inventario generan pérdidas de tiempo, diferencias de stock y problemas operativos.

Stockeame busca ofrecer una herramienta para centralizar la información de los productos y facilitar el control del inventario mediante una interfaz sencilla e intuitiva.

## Funcionalidades previstas

- **Gestión de productos:** crear, consultar, modificar y desactivar productos.
- **Gestión de sectores:** organizar los productos por sectores.
- **Conteos de inventario:** registrar cantidades físicas y compararlas con el stock del sistema.
- **Dashboard:** visualizar indicadores generales y diferencias de inventario.
- **Historial:** consultar conteos anteriores y analizar diferencias.
- **Autenticación:** acceso mediante usuarios registrados.
- **Importación de Excel:** cargar inventarios de forma masiva (fase futura).
- **Reportes:** analizar la evolución de los inventarios (fase futura).

## Arquitectura prevista

La aplicación estará dividida en tres componentes principales:

- **Frontend:** React y TypeScript para la interfaz de usuario.
- **Backend:** API REST desarrollada con Python y FastAPI.
- **Base de datos:** PostgreSQL para almacenar productos, sectores, usuarios y conteos.
